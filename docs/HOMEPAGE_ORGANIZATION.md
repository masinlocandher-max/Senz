# SENZ website organization

## Customer journey

The homepage leads with strategic communications connected to digital solutions. Website rental for freelancers and startups is the second section, followed by the 13 catalog products, the Partner Program, and a three-step introduction to working with SENZ. Returning clients have a separate access path in the header and closing section.

The shared navigation uses explicit destinations: Communications, Website rental, Digital products, Partners, About and Contact. It expands within the page on smaller screens. Escape closes it and returns focus to Menu. The links also work without JavaScript.

Rental leads to the existing website selector and quote handoff. Rental fees, support, renewal and cancellation terms require a quote; no new prices or immediate activation claims are introduced. Public address examples and acquisition hostnames have been removed from public configuration, copy and site documentation. Existing customer domain rights remain explained.

## Design and implementation

One shared control stylesheet gives buttons raised surfaces, rounded shapes, visible keyboard focus and appropriate touch targets. Action buttons stay in the normal page layout, separate from imagery. Large questionnaire choices use a softer 16px radius for readable multiline labels. Reduced-motion preferences disable hover movement. No new dependencies, routes or infrastructure were added.

The homepage is generated by `scripts/render-home.mjs`. Its groups and journey are defined in `components/home-content.json`; product names and descriptions come directly from the existing product catalog. The catalog now opens with its own product explanation. The existing interactive CRM, Booking and QR Menu previews are preserved in a catalog disclosure, backed by `components/product-previews.html`.

## Concept and fidelity review

The built-in Image Gen tool produced [the complete concept](evidence/home-concept.webp) before implementation. Prompt direction: an editorial SENZ homepage in white, navy, cobalt and ice; a split communications hero; rental second with a fictional photographer website; three open product lists; navy partnership section; a concise three-step journey; raised rounded controls in normal flow; no domains, invented prices or client claims. The concept is design evidence, not a runtime page image.

| Area | Browser result and intentional differences |
| --- | --- |
| Layout and hierarchy | Split hero, ice rental section, three product groups, navy partnership and white closing journey match the concept order. |
| Navigation | Explicit offer labels are preserved; the real SENZ mark and FMB&CO attribution replace the concept wordmark. Mobile navigation expands in flow. |
| Typography | Existing self-hosted Inter remains; large navy hero type, clear section titles and restrained supporting text follow the concept. |
| Color | Existing SENZ navy `#010522`, cobalt `#003df9`, ice `#edf3ff` and white are retained. |
| Controls and spacing | Raised pills, generous gaps and separate CTA rows follow the concept. There are no hero buttons positioned over an image. |
| Imagery | Existing SENZ glass architecture and botanical photography replace the concept's new photos. The website preview is native HTML with a visible fictional-identity caption. |
| Product content | Authoritative catalog descriptions replace the concept's illustrative shorthand. All 13 products are linked, with a clear availability notice. |
| Partnership | The concept's layout is preserved; wording reflects eligible products and agreed support, without promising income or automatic approval. |
| Mobile and motion | Columns stack, product groups become readable lists, and controls retain large targets. Native browser review covered the 390px layout and menu keyboard behavior. Reduced motion and no-JavaScript paths remain in browser tests. |

## Verification

- `npm run check`: repository source, syntax and the shared 13-product contract.
- `npm test`: 43 tests covering source consistency, metadata, links, ownership, release limits, domain-free public address options, form validation and delivery behavior.
- `npm run build:products`: repeated generation is stable across all public pages.
- `npm run test:browser`: all 42 pages at 320/390/1440px, axe accessibility checks, mobile menus, existing form flows, questionnaire paths, catalog previews, disclosures, cost planner, website selector, reduced motion and no-JavaScript behavior.
- Native browser review independently verifies the visual hierarchy and in-flow navigation. Temporary mobile QA pages are excluded from delivery.

The browser form suite uses the real inquiry server with a local stand-in email provider. It does not send customer inquiries or establish production email delivery. Product release state, approved catalog prices, application entitlements and the GitHub Pages publisher remain unchanged.
